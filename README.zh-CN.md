# a-stock-chips · A股筹码透视工具（免费版）

> **散户的机构级筹码透视镜** — 基于公开数据的可验证筹码推演
> 「看清主力成本在哪、谁在买、谁被套」

---

## 这是什么

用公开数据（东方财富/新浪财经/腾讯财经/交易所披露）+ Hikyuu 本地K线，还原机构视角的筹码结构：

| 能力 | 说明 |
|---|---|
| **明盘筹码** | 股东户数趋势 / 十大流通股东变动 / 龙虎榜 / 大宗交易 / 两融 / 主力资金流 |
| **暗盘筹码** | Hikyuu 三角形分布模型推演：获利盘比例 / 平均成本 / 90%成本区间 / 筹码峰 / 主力成本区 / 250日换手 |
| **交叉判定** | 现价 vs 筹码峰 vs 20日成本 → 突破形态 / 高位风险区 / 派发形态 |

## 快速开始

```bash
pip install requests numpy
# 暗盘筹码计算需要 Hikyuu: pip install hikyuu  (https://github.com/fasiondog/hikyuu)

python chip_report.py 600844          # 单只 (自动判断市场)
python chip_report.py 600844,000938   # 批量 (专业版功能)
python chip_report.py 600844 --save   # 保存报告
```

## 数据源与可靠性

- **多源容灾**: 东财 push2 被风控 → 腾讯兜底 → 新浪兜底（免费接口常见封 IP，脚本已内置重试+降级）
- **数据新鲜度校验**: 股东户数最新记录 >400 天 = 数据源缺失（改名票），如实提示不误导
- **实时价核对**: Hikyuu K线可能滞后，自动用腾讯实时价重算获利盘
- **已知限制**: 北交所历史K线缺失时降级为简化分析；非两融标的自动跳过
